### **Technical Blueprint & Context: Shark City Drum & Dance Corps (SCD) Application**

**Document Version:** 1.0
**Project Codename:** `scd_app`
**Primary Build Target:** Flutter Web (Dark Theme)

#### **1. Project Manifest & Core Technologies**

*   **Project:** A modern, responsive web application for the Shark City Drum & Dance Corps, built with a single codebase for future mobile deployment.
*   **Primary Goal:** Replace the existing Wix site with a dynamic, high-performance application served via Firebase Hosting.
*   **Core Framework:** **Flutter** (using CanvasKit web renderer for maximum fidelity: `flutter build web --web-renderer canvaskit`).
*   **Backend & Infrastructure:** **Firebase**
    *   **Database:** Cloud Firestore (NoSQL)
    *   **Storage:** Cloud Storage for Firebase
    *   **Hosting:** Firebase Hosting
    *   **Authentication:** Firebase Authentication
*   **State Management:** **Provider** package.
*   **Routing:** **GoRouter** package for URL-based navigation.

#### **2. UI/UX Design System (Dark Theme Specification)**

This system defines the visual language of the application.

*   **Color Palette:**
    *   `background`: `Color(0xFF0A0A0A)` (Slightly off-black)
    *   `surface`: `Color(0xFF1A1A1A)` (For cards, modal backgrounds)
    *   `primary`: `Color(0xFFD4AF37)` (Gold accent for buttons, links, active states)
    *   `onBackground`: `Color(0xFFFFFFFF)` (Primary text on black)
    *   `onSurface`: `Color(0xFFE0E0E0)` (Secondary text on cards)
    *   `onPrimary`: `Color(0xFF000000)` (Text on gold buttons)

*   **Typography (using `google_fonts` package):**
    *   **Font Family (Headings):** `Montserrat`
    *   **Font Family (Body):** `Lato`
    *   **Type Scale:**
        *   `displayLarge` (Hero Title): `Montserrat`, 48pt, Bold (`w700`)
        *   `headlineMedium` (Page Titles): `Montserrat`, 28pt, SemiBold (`w600`)
        *   `titleLarge` (Card Titles): `Montserrat`, 20pt, Medium (`w500`)
        *   `bodyLarge` (Body Text): `Lato`, 16pt, Regular (`w400`)
        *   `bodyMedium` (Captions/Subtext): `Lato`, 14pt, Regular (`w400`)
        *   `labelLarge` (Button Text): `Montserrat`, 16pt, SemiBold (`w600`)

*   **Layout & Spacing:**
    *   **Grid System:** 8pt grid. All padding, margins, and spacing should be multiples of 8 (e.g., 8, 16, 24, 32).
    *   **Max Content Width:** `1200px`. On larger screens, content should be centered with this maximum width.
    *   **Responsive Breakpoints:**
        *   `Mobile`: < 600px
        *   `Tablet`: 600px - 900px
        *   `Desktop`: > 900px

*   **Component States:**
    *   **Buttons/Links:** Implement a subtle opacity change on hover (`opacity: 0.85`).
    *   **Active Navigation Links:** Should use the `primary` (gold) color.

#### **3. Firebase Firestore Schema & Data**

This is the definitive structure for the database.

##### **Collection: `app_content`**
*   **Purpose:** Stores singleton documents for global site content.
*   **Document (`main`):**
    *   `missionStatement` (String): "To use the performing arts as a vehicle for youth development, fostering discipline, self-expression, leadership, and community engagement."
    *   `visionStatement` (String): "To be a leading force in youth development through the performing arts, empowering our members to become responsible citizens and leaders who create a positive impact in their communities and beyond."
    *   `history` (String): "Founded with a passion for rhythm and a commitment to our youth, Shark City Drum & Dance Corps has grown from a small community group into a beacon of artistic excellence and mentorship. We provide a structured, supportive environment where young performers can hone their craft, build lifelong friendships, and develop the character needed to succeed in all aspects of life."

##### **Collection: `staff`**
*   **Purpose:** Stores profiles for all staff and board members.
*   **Document Structure:**
    *   `name` (String): e.g., "Ronald Clark"
    *   `role` (String): e.g., "Executive Director"
    *   `bio` (String): e.g., "With over 20 years of experience in youth mentorship and performing arts management, Ronald leads SCD with a vision for excellence and community impact."
    *   `photoUrl` (String): Public URL from Firebase Storage. e.g., `https://firebasestorage.googleapis.com/.../staff/ronald_clark.jpg`
    *   `displayOrder` (Number): For sorting on the page (e.g., 1, 2, 3...).
*   **Initial Documents:**
    *   **Doc 1:** `{ name: "Ronald Clark", role: "Executive Director", displayOrder: 1, ... }`
    *   **Doc 2:** `{ name: "Angela Hill", role: "VP of Performance", displayOrder: 2, ... }`
    *   *(Add other known staff members here)*

##### **Collection: `events`**
*   **Purpose:** Manages all upcoming and past performances, workshops, and auditions.
*   **Document Structure:**
    *   `title` (String): e.g., "Annual Winter Showcase"
    *   `date` (Timestamp): Firestore Timestamp object for the event start time.
    *   `locationName` (String): e.g., "The Grand Civic Auditorium"
    *   `locationAddress` (String): e.g., "123 Main St, City, State 12345"
    *   `description` (String): Detailed event info.
    *   `imageUrl` (String): Public URL from Firebase Storage.
    *   `type` (String): Enum: "Performance", "Workshop", "Audition", "Community Event".
*   **Initial Documents:**
    *   **Doc 1:** `{ title: "Annual Winter Showcase", date: <Timestamp for Dec 15>, locationName: "The Grand Civic Auditorium", type: "Performance", ... }`
    *   **Doc 2:** `{ title: "Spring Auditions", date: <Timestamp for Mar 10>, locationName: "SCD Rehearsal Hall", type: "Audition", ... }`

##### **Collection: `gallery_items`**
*   **Purpose:** Aggregates all media for the gallery page.
*   **Document Structure:**
    *   `type` (String): Enum: "photo" or "video".
    *   `url` (String): Public URL from Firebase Storage (for photos) or a YouTube/Vimeo embed URL (for videos).
    *   `thumbnailUrl` (String, for videos): Public URL to a custom thumbnail image in Firebase Storage.
    *   `caption` (String): e.g., "Drumline at the 2024 Nationals"
    *   `category` (String): e.g., "Performances", "Rehearsals", "Travel"
    *   `timestamp` (Timestamp): Date the media was created/uploaded.
*   **Initial Documents:**
    *   **Doc 1:** `{ type: "photo", url: "<URL to event_drumline.jpg>", category: "Performances", ... }`
    *   **Doc 2:** `{ type: "photo", url: "<URL to event_dance.jpg>", category: "Performances", ... }`
    *   **Doc 3:** `{ type: "video", url: "https://www.youtube.com/embed/dQw4w9WgXcQ", thumbnailUrl: "<URL to a video thumbnail>", caption: "Watch our 2024 recap!", ... }`

#### **6. Component Blueprints**

*   **`EventCard` Widget:**
    *   **Purpose:** Display a summary of a single event.
    *   **Parameters:** `final EventModel event;`
    *   **Composition:** `Stack` > `CachedNetworkImage` (with gradient overlay) > `Column` > `Text` (Date), `Text` (Title), `Text` (Location).
    *   **Behavior:** `onTap` gesture detector that uses `GoRouter.of(context).go('/events/${event.id}')`.

*   **`AppHeader` Widget:**
    *   **Purpose:** Provide consistent site navigation.
    *   **Parameters:** None.
    *   **Composition:** `AppBar` > `Row` > `LogoWidget`, `Spacer`, `ResponsiveNavLinks`, `DonateButton`.
    *   **Behavior:** Uses a `LayoutBuilder` to switch between `Row` of text links (desktop) and an `IconButton` (mobile) that opens a `Drawer`.

#### **7. Feature Implementation Roadmap (Technical Tasks)**

This is the build order.

1.  **Foundation:**
    *   [ ] Setup Flutter project, Git, and Firebase.
    *   [ ] Implement `app_theme.dart` with specified colors and typography.
    *   [ ] Configure `app_router.dart` with all page routes.
    *   [ ] Build the main app shell with a responsive `AppHeader` and `AppFooter`.

2.  **Data Layer:**
    *   [ ] Create Dart models for all Firestore collections.
    *   [ ] Implement the `FirestoreService` with methods to fetch each data type (e.g., `Future<List<Event>> getUpcomingEvents()`).
    *   [ ] Create a `ChangeNotifierProvider` for each data model.

3.  **UI Development (Component-Driven):**
    *   [ ] Build the `EventCard`, `PillarCard`, and `CustomButton` widgets using static data.
    *   [ ] Assemble the Home Page, Events Page, and other pages using the static components.
    *   [ ] Connect the UI to the `Providers`, replacing all static data with live data from Firestore. Implement `FutureBuilder` or `Consumer` widgets to handle loading/error states.

4.  **Deployment:**
    *   [ ] Configure `web/index.html` with SEO metadata.
    *   [ ] Run `flutter build web --web-renderer canvaskit`.
    *   [ ] Deploy the build to Firebase Hosting.
    *   [ ] Update DNS records at Wix. Test and verify the live domain.
