# Shark City Drum & Dance Corps (SCD) Web & Mobile Application

This document provides comprehensive context for building the SCD web and mobile application using Flutter and Firebase. It details the project's vision, design guidelines, technical architecture, and implementation plan, specifically focusing on the dark theme as the primary build.

---

## 1. Project Overview

*   **Goal:** Replace the existing Wix website (`sharkcitydrum.com`) with a modern, dynamic, and performant Flutter web application. This codebase will serve as the foundation for native iOS and Android mobile apps in a later phase.
*   **Future Scope:** The architecture is designed to accommodate a comprehensive CRM system (for students, parents, clients, donors, staff management) post-initial launch.
*   **Target Audience:** Youth, parents, event organizers, donors, sponsors, and the broader community.

---

## 2. Brand & Design Guidelines (Dark Theme Focus)

We are building primarily against the **Dark Theme** mockups.

*   **Primary Color Palette:**
    *   **Backgrounds:** Black (`#000000`)
    *   **Text (Primary):** White (`#FFFFFF`)
    *   **Accents/CTAs/Active States:** Gold (`#D4AF37` or similar vibrant gold)
    *   **Secondary Text/Subtle Elements:** Light Gray (`#A0A0A0` or similar for contrast on dark backgrounds)
*   **Typography:**
    *   **Headings (H1, H2, etc.):** A bold, modern sans-serif. (`Montserrat` or `Poppins` are good candidates).
    *   **Body Text:** A clean, readable sans-serif. (`Lato` or `Roboto` are good candidates).
    *   **Font Weights:** Utilize appropriate weights (e.g., bold for headings, regular for body) to establish hierarchy.
*   **Imagery:**
    *   High-quality, dynamic photos of SCD youth performing, emphasizing energy, discipline, and community.
    *   Uniforms in **black, white, and gold only**.
    *   **No specific faces should be recreated or focused on**; images should be diverse and representative.
*   **Key UI Elements:**
    *   **Header/AppBar:** Black background, gold logo, white navigation links, prominent gold "DONATE" button.
    *   **Footer:** Dark background, white copyright text, subtle gold accents for links.
    *   **Cards (Events, Pillars):** Darker gray/black backgrounds with white text and gold accents/icons for contrast.
    *   **Buttons:** Predominantly gold background with white/black text, subtle hover/tap effects.
    *   **Icons:** Gold colored.
*   **Hero Section:** Features a dynamic image of SCD youth with a prominent headline ("EMPOWERING YOUTH THROUGH RHYTHM & DANCE") and a gold "SEE OUR IMPACT" button. The background for the hero section image itself is black for dark mode.
*   **Responsiveness:** All layouts must gracefully adapt from desktop (web) to mobile (iOS/Android) views.
    *   Desktop navigation: Horizontal links in the header.
    *   Mobile navigation: Hamburger menu for main navigation, potentially a `BottomNavigationBar` for primary sections.

---

## 3. Technical Stack & Infrastructure

*   **Frontend Framework:** Flutter (latest stable version).
*   **IDE:** VS Code.
*   **Version Control:** Git (repository to be provided/initialized).
*   **Backend Services:** Firebase.
    *   **Database:** Cloud Firestore (NoSQL).
    *   **Storage:** Firebase Storage (for images and media).
    *   **Authentication:** Firebase Authentication (initially for admin login, later for staff/parents).
    *   **Hosting:** Firebase Hosting (for web deployment).
*   **Deployment Targets:**
    *   **Primary (Phase 1):** Web (`flutter build web`).
    *   **Secondary (Phase 2):** iOS (`flutter build ios`), Android (`flutter build appbundle`).
*   **Domain Management:** `sharkcitydrum.com` is registered with Wix. DNS records will be updated to point to Firebase Hosting.
*   **Accounts:** Google Dev, Google Cloud, Firebase, Apple Developer, Google Play Developer.
